## 10. OPERAÇÃO E PROCESSOS

### 10.1 Fluxo Operacional PUDO — Retirada

```
Transportadora entrega pacote
        ↓
Conferência + leitura de código (WMS/sistema)
        ↓
Armazenagem por localização (A-Z, dia, transportadora)
        ↓
Notificação ao destinatário (WhatsApp/SMS automático)
        ↓
Cliente apresenta código → entrega + assinatura
        ↓
Baixa no sistema → comissão registrada
```

### 10.2 Fluxo Operacional Logística Reversa — Devolução

```
Cliente chega com produto para devolver
        ↓
Validar QR Code / pedido no sistema do marketplace
        ↓
Conferir item (não abrir embalagem)
        ↓
Gerar etiqueta de retorno (sistema integrado)
        ↓
Acondicionar + embalar se necessário
        ↓
Transportadora coleta (diário ou por demanda)
        ↓
Registro de comissão
```

### 10.3 Fluxo Venda de Produtos (Loja Física + Online)

```
Compra de produtos (fornecedor)
        ↓
Entrada no estoque (ERP / planilha)
        ↓
Cadastro no marketplace / vitrine física
        ↓
Venda (balcão ou pedido online)
        ↓
Separação + embalagem
        ↓
Entrega (motoboy / PUDO / correios)
        ↓
Pós-venda e avaliação
```
